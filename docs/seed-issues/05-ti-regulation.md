# Ticino: zoning (piano regolatore) and NAPR rules
Labels: good first canton,adapter,i18n/it

Ticino has no ÖREB cadastre yet (status *Einführung geplant*). Cantonal geoportal (map.geo.ti.ch, OGD) publishes the *piani regolatori* per comune; regulations (NAPR) are per municipality — start with Lugano (indice di sfruttamento, altezza, distanze).
