# Example reports

Generated by the real pipeline on 2026-09-08 (`topoli audit`), committed so the README and the website can show real output without running anything. Each folder holds `index.html` (self-contained report), `evidence.json` (layer 2), `geometry.geojson`, `summary.txt`, `card.png`, `card-square.png` and `map.jpg`. The `raw/` folders (source responses) are not committed — regenerate with `topoli audit` to get them.
